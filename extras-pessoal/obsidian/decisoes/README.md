# Decisões

Notas escritas à mão (sem `gerado: true`), uma por decisão ou lição
aprendida, com a tag `#decisao` e links para os labs, as seções do spec e
os commits relacionados. Exemplo de início:

```markdown
---
tags: [decisao]
---
# Labs de D03 sem subpasta adaptacao-ams

Tentado e revertido em D03 — ver [[D03]] e [[9b528e0]].
```

O gerador (`extras-pessoal/scripts/gerar_vault.py`) nunca toca esta pasta.
